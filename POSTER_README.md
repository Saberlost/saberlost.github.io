# Willawan Thaimassage Poster

This poster is designed to be printed in A4 landscape format (297mm x 210mm) for display.

## Features
- Professional design matching the website's color scheme
- QR code linking to www.willawanthaimassage.se for easy booking
- Business name: Willawan Thaimassage i Sköndal
- Complete contact information (address, phone, opening hours)
- Profile picture and services list

## How to Print

### Option 1: Using a Web Browser
1. Open `poster.html` in any modern web browser (Chrome, Firefox, Safari, Edge)
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac) to open the print dialog
3. Select these settings:
   - **Paper size**: A4
   - **Orientation**: Landscape
   - **Margins**: None (or Minimum)
   - **Scale**: 100%
4. Either print directly to a printer or save as PDF

### Option 2: Save as PDF First
1. Follow steps 1-3 above
2. Choose "Save as PDF" as the destination
3. Save the PDF file to your computer
4. Print the PDF using your preferred PDF viewer

## Recommended Print Settings
- **Paper**: A4 (210mm x 297mm)
- **Orientation**: Landscape (sideways)
- **Quality**: High quality or Best
- **Color**: Color printing recommended for best results
