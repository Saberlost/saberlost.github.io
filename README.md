# Willawan Thaimassage

Statisk webbplats för [Willawan Thaimassage](https://www.willawanthaimassage.se) i Sköndal — publicerad via GitHub Pages.

## Lokal förhandsvisning

```bash
npm install
npm start
```

Öppna sedan [http://localhost:3000](http://localhost:3000).

## Struktur

- `index.html` — sida och innehåll
- `style.css` — layout och design
- `images/` — galleri, personal och övriga bilder
- `CNAME` — custom domain för GitHub Pages
- `AGENTS.md` — projektkontext för framtida AI-/dev-arbete
