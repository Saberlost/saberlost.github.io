# Bilder / Images

Denna mapp innehåller bilder för Willawan Thaimassage webbsidan.

## Mappstruktur / Directory Structure

- `gallery/` - Bilder från salongen och behandlingar
- `personal/` - Personliga foton av teammedlemmar

## Galleribilder / Gallery Images

Placera galleribilder i mappen `gallery/` med följande filnamn:

- `image1.jpg` - Behandlingsrum
- `image2.jpg` - Avslappnande miljö
- `image3.jpg` - Hot Stone Massage
- `image4.jpg` - Massagerum
- `image5.jpg` - Spa-område
- `image6.jpg` - Behandling

**Rekommenderad bildstorlek:** 800x600 pixlar (4:3 format)

## Personliga Bilder / Personal Photos

Placera personliga foton i mappen `personal/` med följande filnamn:

- `personal1.jpg` - Willawan (grundare)
- `personal2.jpg` - Terapeut 2
- `personal3.jpg` - Terapeut 3

**Rekommenderad bildstorlek:** 400x400 pixlar (kvadratisk format för bästa resultat)

## Bildformat / Image Formats

Stödda format: JPG, PNG, WebP

## Tips

- Använd högkvalitativa bilder som visar salongen och teamet professionellt
- Optimera bilderna för webben (komprimera utan att förlora för mycket kvalitet)
- Se till att bilderna är väl belysta och visar lokalerna tydligt
